Časté dotazy

Jak nastavit n8n, aby s aplikací fungovalo?
Stačí trigger On chat message se zapnutou volbou Make Chat Publicly Available, AI Agent s modelem a Simple Memory ve výchozím nastavení a publikované workflow. Chat URL vložte v aplikaci jako adresu serveru. Podrobný návod s printscreeny je v aplikaci pod ikonou ⓘ.
Aplikace hlásí „Webhook nenalezen (HTTP 404)“.
Workflow není publikované (tlačítko Publish), nebo je adresa špatně. U chat triggeru musí adresa končit na /chat; u Webhook node použijte Production URL, ne Test URL.
Aplikace hlásí „Přístup odepřen (HTTP 401/403)“.
Autentizace v aplikaci neodpovídá nastavení v n8n. Zkontrolujte typ autentizace a údaje. U přihlášení účtem n8n mohlo přihlášení vypršet (výchozí platnost je 7 dní) – přihlaste se znovu v nastavení serveru.
Proč nejde zadat adresa s http://?
Kvůli bezpečnosti aplikace komunikuje jen přes šifrované HTTPS. Pro n8n v domácí síti použijte například reverzní proxy s certifikátem.
Místo textu se zobrazí JSON, nebo nic.
Aplikace čte text z klíče output (výstup AI Agenta), případně text, message a dalších. Jinou cestu nastavíte u serveru v poli „Cesta k textu v JSON odpovědi“. U Webhook node zkontrolujte, že má Respond nastavené na When Last Node Finishes.
AI agent si nepamatuje předchozí zprávy.
Připojte k agentovi Simple Memory (nebo jinou paměť). S chat triggerem funguje ve výchozím nastavení; u Webhook node nastavte klíč session na {{ $json.body.sessionId }}. Nová session v aplikaci záměrně začíná s čistou pamětí.
Odpověď se nezobrazuje průběžně, ale až celá.
V chat triggeru nastavte Options → Response Mode na Streaming. AI Agent streamuje ve výchozím nastavení. Aplikace streamovanou odpověď rozpozná sama.
Dostanu odpověď, i když aplikaci zavřu?
Ano. Zpráva se dokončí na pozadí a po doručení odpovědi přijde notifikace (pokud jste oznámení povolili).
Jak změním jazyk aplikace?
V Nastavení aplikace (ozubené kolo v seznamu serverů). Volba „Podle telefonu“ použije jazyk systému.
Jak smažu svá data?
Chat nebo server smažete ikonou koše přímo v aplikaci. Vše najednou smažete vymazáním dat aplikace v nastavení Androidu nebo odinstalováním. Autor žádná vaše data nemá. Podrobnosti v Zásadách ochrany soukromí.
