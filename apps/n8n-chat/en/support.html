FAQ

How do I set up n8n to work with the app?
All you need is the On chat message trigger with Make Chat Publicly Available turned on, an AI Agent with a model and Simple Memory with default settings, and a published workflow. Paste the Chat URL as the server address in the app. A detailed guide with screenshots is in the app under the ⓘ icon.
The app says “Webhook not found (HTTP 404)”.
The workflow is not published (the Publish button) or the address is wrong. For the chat trigger the address must end with /chat; for the Webhook node use the Production URL, not the Test URL.
The app says “Access denied (HTTP 401/403)”.
The authentication in the app does not match n8n. Check the authentication type and credentials. With n8n account sign-in the session may have expired (7 days by default) – sign in again in the server settings.
Why can’t I use an http:// address?
For security the app communicates over encrypted HTTPS only. For n8n on your home network use, for example, a reverse proxy with a certificate.
I see JSON instead of text, or nothing at all.
The app reads the text from the output key (AI Agent output), or text, message and others. Set a different path in the server’s “Path to the text in the JSON response” field. For the Webhook node make sure Respond is set to When Last Node Finishes.
The AI agent does not remember previous messages.
Connect Simple Memory (or another memory) to the agent. With the chat trigger it works with default settings; for the Webhook node set the session key to {{ $json.body.sessionId }}. A new session in the app intentionally starts with a clean memory.
The reply appears all at once instead of word by word.
In the chat trigger set Options → Response Mode to Streaming. The AI Agent streams by default and the app detects a streamed reply automatically.
Will I get the reply if I close the app?
Yes. The message is completed in the background and a notification arrives with the reply (if notifications are allowed).
How do I change the app language?
In the app Settings (gear icon in the server list). “System default” uses the phone language.
How do I delete my data?
Delete a chat or server with the trash icon in the app. Delete everything at once by clearing the app data in Android settings or uninstalling the app. The developer holds none of your data. See the Privacy Policy for details.
